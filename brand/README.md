# 아기장수우투리 로고

선택된 A안은 겨드랑이에 난 날개와 달리는 어린 장수의 실루엣을 결합한 심볼입니다. 개인 운동의 활력과 꾸준한 전진을 표현합니다.

- 기본색: 숲빛 청록 `#285D55`
- 밝은 배경: 따뜻한 아이보리 `#F3F0E8`
- `wooturi-mark.png`: 투명 배경의 기본 심볼, 사진 스탬프·소개 자료용
- `wooturi-small.svg`: 작은 화면용으로 단순화한 벡터 심볼
- `wooturi-black.svg` / `wooturi-white.svg`: 단색·반전 벡터 심볼
- `../icon.svg`: 아이보리 배경 앱 아이콘

심볼 주변에는 머리 크기의 절반 이상 여백을 두세요. 심볼 비율을 늘리거나 줄이지 말고, 가로세로 비율을 유지해 사용합니다. 작은 아이콘에서는 얼굴이나 깃털 디테일을 추가하지 않습니다.

기본 심볼은 래스터 원본이며, 소형 SVG는 같은 방향을 유지해 별도로 단순화한 버전입니다. 상표 등록 가능성이나 유사 상표는 별도 확인이 필요합니다.
