## 어떤 앱인가요?

아기장수우투리는 Apple 건강에서 내보낸 운동·활동 기록을 브라우저에서 읽는 개인 운동 기록장입니다. 별도의 앱 설치나 회원가입 없이 iPhone Safari에서 시작할 수 있습니다. 겨드랑이에 날개가 난 어린 장수 우투리가 달리는 로고에는 일상의 움직임에서 힘을 발견한다는 뜻을 담았습니다.

## 바로 시작하기

1. iPhone **건강 앱 → 오른쪽 위 프로필 → 모든 건강 데이터 내보내기**를 선택합니다.
2. 내보낸 ZIP을 **파일 앱**에 저장합니다.
3. [웹앱](https://wnh9310-ai.github.io/babyGeneral-WOOTURI/)의 메인 화면에서 **기록 파일 선택해서 가져오기**를 누르고 ZIP을 선택합니다.
4. 운동 기록을 눌러 상세 지도·심박·고도·속도·구간 기록을 확인합니다.
5. Safari **공유 → 홈 화면에 추가**로 앱처럼 사용할 수 있습니다.

ZIP에 XML과 GPX가 들어 있으면 함께 읽어 운동과 경로를 연결합니다. 개별 XML·GPX 파일을 함께 선택하거나, 지원 형식의 단축어 JSON을 가져올 수도 있습니다. Apple 건강과 브라우저를 직접 연결하는 자동 동기화는 제공하지 않습니다. 새 기록은 갱신된 파일을 다시 선택해 반영합니다.

## 주요 화면

| 화면 | 할 수 있는 일 |
| --- | --- |
| **운동** | 기록 가져오기, 종목·이름 검색, 거리·시간·페이스·활동 에너지 확인 |
| **운동 상세** | OpenStreetMap 경로, 고도·XML 심박·속도 겹침 그래프, GPS 구간 분석, 경로 영상 재생·저장 |
| **활동** | 이번 주 운동 요약, 걸음 수 추이, 최근 운동 |
| **분석** | 기간별 활동, 월간 캘린더·최근 16주 활동 분포, 종목별 기록, 심박 구간 |
| **코칭** | 가져온 기록을 근거로 한 기기 내 규칙 분석과 요약 |
| **사진** | 사진 위 경로 스탬프 8종, 배경 제거, 크기 조절, 드래그 배치, 합성 이미지 저장 |

### 그래프와 경로 영상

고도·심박·속도는 단위가 다르므로 각 지표의 최저–최고를 같은 높이로 맞춰 겹쳐 표시합니다. Y축의 백분율은 비교용 배율이며, 실제 단위 값은 범례와 선택한 지점에 표시합니다. XML 심박 표본은 기록 시각을 기준으로 GPS 거리와 연결합니다. GPS 시각과 연결되지 않는 표본은 그래프에서 제외합니다.

경로 영상은 **지도 타일 배경 없이 경로 선과 운동 수치를 그리는 12초 애니메이션**입니다. 재생 중 지도 위치와 그래프 선택 지점도 함께 이동합니다. 저장 형식은 브라우저가 지원하는 MP4 또는 WebM이며, 지원하지 않는 브라우저에는 안내가 표시됩니다.

## 개인정보는 어디에 저장되나요?

- 가져온 건강 기록은 **해당 기기·브라우저의 IndexedDB**에 저장합니다. 앱 코드는 원본 건강 ZIP/XML/GPX를 서버에 업로드하지 않습니다.
- 사진은 브라우저 메모리에서 편집합니다. 저장 시 합성 이미지를 내려받습니다.
- GitHub Pages는 웹앱 파일을 제공합니다. 접속 시 IP 등 일반적인 웹 요청 정보는 호스팅 제공자에게 전달될 수 있습니다.
- OpenStreetMap은 지도를 표시하기 위해 **표시 지역의 지도 타일 요청과 IP**를 받습니다. 경로 선은 브라우저에서 그립니다.
- 코드와 로고는 이 공개 저장소에서 볼 수 있습니다. 개인의 가져온 건강 기록은 저장소에 포함되지 않습니다.
- 기기·브라우저·웹 주소가 달라지면 저장 공간도 달라집니다. 로컬 개발 주소의 데이터는 공개 웹 주소로 자동 이전되지 않습니다.
- 브라우저 데이터를 지우면 기록도 사라질 수 있습니다. **활동 → 내 데이터 JSON으로 내보내기**로 백업하세요.

## 현재 지원 범위

- 코칭은 생성형 AI가 아닌 **기기 내 규칙 분석**입니다. 외부 AI 서비스 연결은 아직 제공하지 않습니다.
- 단축어 JSON 가져오기는 지원하지만 설치용 단축어·iCloud 공유 링크는 아직 제공하지 않습니다.
- 경로가 없는 운동은 지도 위 운동 경로를 표시할 수 없습니다. XML만으로 GPS 좌표를 복원하지 않습니다.
- 거리·고도·속도·심박은 원본 데이터의 기록 여부와 품질에 따라 달라집니다. 추정 거리와 기록 누락을 구분해 표시합니다.
- 지도 타일에는 인터넷 연결이 필요합니다. iPhone 실기기에서 모든 파일·영상 저장 조합을 검증한 것은 아닙니다.

## 개발·확인

빌드 과정이나 앱 서버 없이 정적 파일로 동작합니다.

```sh
# 이 저장소를 받은 폴더에서
python3 -m http.server 4175
# http://localhost:4175 에서 확인

# 순수 로직 테스트
node --test tests/*.test.mjs
```

원본 통합 프로젝트에서는 `python3 -m http.server 4175 --directory web`와 `node --test web/tests/*.test.mjs`를 사용합니다.

지도는 [Leaflet 1.9.4](https://leafletjs.com/)와 [OpenStreetMap](https://www.openstreetmap.org/copyright)을 사용합니다. Leaflet 라이선스는 [vendor/leaflet/LICENSE](./vendor/leaflet/LICENSE)에 포함되어 있습니다. 지도 출처 표시를 유지하고 타일 대량 다운로드·미리 받기를 제공하지 않습니다.
